## A. Identification

- [ ] Triggering behavior recorded.
- [ ] Detection source and timestamp captured.
- [ ] Incident ID assigned.
- [ ] Initial severity proposed, with rationale.
- [ ] Uncertainty and missing information recorded.

## B. Evidence preservation

- [ ] Relevant logs preserved.
- [ ] Manifest, configuration, and version identifiers preserved.
- [ ] Diffs and test outputs preserved.
- [ ] Evidence copied to approved storage.
- [ ] Evidence hashes or integrity metadata recorded where supported.
- [ ] Original evidence left unmodified.

## C. Scope and assessment

- [ ] Requested authority identified.
- [ ] Actual permissions independently inspected.
- [ ] Any state change confirmed or ruled out with evidence.
- [ ] Reachable systems, credentials, and data assessed.
- [ ] Severity reviewed by a human.

## D. Containment

- [ ] Containment proposal documented.
- [ ] Side effects and recovery path documented.
- [ ] Human authorizer recorded.
- [ ] Operator and action timestamp recorded.
- [ ] Result independently verified.
- [ ] If not contained, rationale and compensating controls recorded.

## E. Governance verification

- [ ] No self-authorization accepted.
- [ ] No self-validation accepted as independent proof.
- [ ] Independent review completed.
- [ ] Provenance chain checked.
- [ ] Tests assert the intended security property.
- [ ] Reality Anchor evidence recorded.

## F. Recovery

- [ ] Known-good state identified.
- [ ] Provenance of recovery source verified.
- [ ] Remediation independently reviewed.
- [ ] Recovery plan and rollback path documented.
- [ ] Steward authorization recorded.
- [ ] Post-recovery state verified.

## G. SLA and closure

- [ ] Acknowledgement and decision times recorded.
- [ ] SLA status and any breach documented.
- [ ] Corrective actions assigned owners and due dates.
- [ ] Residual risk documented.
- [ ] Post-incident review completed.
- [ ] Steward closure decision recorded.

**Steward decision:**  
- [ ] Close  
- [ ] Keep open  
- [ ] Accept residual risk
